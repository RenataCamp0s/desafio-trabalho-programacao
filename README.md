Trabalho da disciplina Programacao para Automacao de Testes da PGATS

Desafio:
Construa uma função de para realizar login. Quem usar a função deverá receber uma mensagem dizendo que o login foi realizado com sucesso caso 
exista um usuário com email e senha iguais aos informados. A função deve dizer que as credenciais expiraram caso expirado for true. 
A função também tem que dizer que as credenciais estão incorretas caso o email não exista ou a senha esteja incorreta para aquele email.

Testes:
Escreva 4 testes: 
1) Sucesso,
2) Credencial expirada,
3) Usuario não encontrado,
4) Senha incorreta para o usuário encontrado.
